## Sous-dossier `mahamat/script`

Ce sous-dossier contient plusieurs notebooks Jupyter, script utilisés pour les simulations et les expériences liées aux modèles de diffusion. Le notebook principal utilisé dans le rapport est `anneau_diffusion.ipynb`.

### `anneau_diffusion.ipynb`

Ce notebook simule un processus de diffusion direct et inverse sur une distribution en anneau en 2D. Il trace l'évolution de la densité de probabilité ainsi que la dynamique de $X$ dans les deux sens (forward et reverse). Les méthodes numériques utilisées s'appuient sur le schéma d'Euler–Maruyama pour résoudre les SDEs.

**Références**:
Cf `rapport/TER_Diffusion_Model`

Le code utilisé dans le chapitre  est principalement tiré de ce notebook.
